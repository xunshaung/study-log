# 学习记录

每天一条,按 `年/年-月-日.md` 存放。

```
2026/
  2026-10-09.md
_template.md     # 新建记录时套用的模板,内容可以自己改
```

## 每天怎么写

在终端运行:

```bash
study
```

它会建好当天的文件并打开编辑器。写完保存退出,自动提交并推送到这里。

其他命令:

| 命令 | 作用 |
| --- | --- |
| `study` | 写今天的记录,保存退出后自动提交推送 |
| `study push` | 只提交并推送(上次推送失败时用来重试) |
| `study open` | 只打开今天的文件,不提交 |

## 也可以直接在网页上改

在 github.com 上点开文件、编辑、提交,效果一样。终端下次运行 `study` 时会先拉取,再把网页上的改动同步下来。

## 注意

这是公开仓库,不要写密码、API key、身份证号、家庭住址等敏感信息。
